Theory: Vernier Callipers & Least Count

Principle: The Vernier Callipers utilizes the principle of difference between two scales: the Main Scale and the Vernier Scale. If $N$ divisions on the Vernier scale coincide with $(N - 1)$ divisions on the main scale, the Least Count ($\text{LC}$) is given by:

$$\text{LC} = 1\text{ MSD} - 1\text{ VSD} = \frac{1\text{ MSD}}{N}$$

Zero Error & Correction: When the movable jaw touches the fixed jaw:

  • Nil Error: Vernier zero exactly aligns with Main Scale zero.
  • Positive Zero Error ($+e$): Vernier zero lies to the right of Main Scale zero ($e = + n \times \text{LC}$).
  • Negative Zero Error ($-e$): Vernier zero lies to the left of Main Scale zero ($e = - (N - n) \times \text{LC}$).
  • True Reading: $\text{True Reading} = \text{Observed Total} - (\pm e)$.

Volumetric Formulas:

$$\text{Sphere: } V = \frac{4}{3}\pi \left(\frac{D}{2}\right)^3 \quad\quad \text{Cylinder/Beaker: } V = \pi \left(\frac{D}{2}\right)^2 h$$
