Theory: Vernier Callipers & Least Count

Principle of Vernier: If $N$ divisions of the Vernier scale coincide with $(N - 1)$ divisions of the main scale, the Least Count ($\text{LC}$) is the smallest measurable length:

$$\text{LC} = 1\text{ MSD} - 1\text{ VSD} = \frac{1\text{ MSD}}{N}$$

Zero Error and Correction: When jaws are fully brought in contact:

  • Nil Error: Vernier 0 aligns exactly with Main Scale 0.
  • Positive Error ($+e$): Vernier 0 lies to the right of Main Scale 0 ($e = +n \times \text{LC}$).
  • Negative Error ($-e$): Vernier 0 lies to the left of Main Scale 0 ($e = -(N - n) \times \text{LC}$).
  • Corrected Reading: $\text{True Reading} = \text{Observed Total} - (\pm e)$.

Volumetric Formulas:

$$\text{Sphere: } V = \frac{4}{3}\pi \left(\frac{D}{2}\right)^3 \quad\quad \text{Cylinder/Beaker: } V = \pi \left(\frac{D}{2}\right)^2 h$$
